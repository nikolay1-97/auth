# Подготовка к запуску приложения.
Для запуска приложения нужно установить значения для слудующих
переменных в файле "/.env":

    PORT- порт;

    DB_URL= адрес базы данных;

    SALT- значение для шифрования пароля;

    SUPER_ADMIN_SECRET- значение для генерации токена для суперадмина;

    APP_ADMIN_SECRET- значение для генерации токена для админов приложений;

    EXPIRE_JWT- время действия токена.
## Установка зависимостей.
Для установки зависимостей необходимо выполнить команду "npm install" в 

терминале из корневой директории.
## Выполнение миграций.
Для выполнения миграций необходимо выполнить команду "npx knex migrate:latest"

в терминале из директории "/src/db.
## Заполнение базы данных тестовыми данными.
Для заполнения базы данных тестовыми данными необходимо выполнить команду
"npx knex seed:run" в терминале из директории "/src/db".
## Запуск тестов.
Перед каждым запуском тестов необходимо выполнять команду
"npx knex seed:run" в терминале из директории "/src/db" для заполнения базы даных
тестовыми данными.

Для запуска тестов необходимо выполнить команду "yarn test" в терминале из корневой директории.
## Запуск приложения.
Для запуска приложения необходимо выполнить команду "npm run start:dev"

в терминале из корневой директории.

Api документация доступна по ссылке "http://127.0.0.1:порт/api".
